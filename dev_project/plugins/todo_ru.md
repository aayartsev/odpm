Пока идея реализации плагинов заключается в том, чтобы сделать каталог, в котором будут лежать python модули, и в них будет логика, которая создаст нужные файлы в структуре файловой системы и создавался шаблон для конкретного сервиса в docker-compose.yml. Таким образом мы получим способ директивного добавления дополнительных служб, по мере необходимости.
