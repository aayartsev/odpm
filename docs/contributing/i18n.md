# i18n (gettext)

Каталог: `dev_project/i18n/<locale>/LC_MESSAGES/`.

Поведение: `tests/test_translations.py`, `tests/test_human_summaries.py`.

Пользовательская справка по `ODPM_LOCALE`: [locale.md](../reference/locale.md).

## Обновление после правки `_('...')`

```bash
xgettext -o dev_project/i18n/main.pot -L Python -k_ dev_project/*.py dev_project/**/*.py
msgmerge -U dev_project/i18n/ru_RU/LC_MESSAGES/main.po dev_project/i18n/main.pot
# редактировать .po
msgfmt -o dev_project/i18n/ru_RU/LC_MESSAGES/main.mo \
  dev_project/i18n/ru_RU/LC_MESSAGES/main.po
```

Быстрый путь:

```bash
python3 scripts/sync_i18n_catalog.py
python3 scripts/check_i18n_catalog.py
```

`.mo` в git (исключение в `.gitignore`), в пакет через `package-data` в `pyproject.toml`.
