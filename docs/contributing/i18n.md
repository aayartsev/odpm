# i18n (gettext)

Каталог: `dev_project/i18n/<locale>/LC_MESSAGES/`.

Поведение: `tests/test_translations.py`, `tests/test_human_summaries.py`, `tests/test_ci_i18n.py`.

Политика host vs container: [ADR-008](adr-008-i18n-host-container-policy.md).

Пользовательская справка по `ODPM_LOCALE`: [locale.md](../reference/locale.md).

## Три уровня строк

| Уровень | Где | Перевод |
|---------|-----|---------|
| **User-facing host** | CLI ошибки, wizard, `database`/`plan` | `_()` / `plan_msg()` + `ru_RU` — **обязательно** |
| **Human summaries** | `host_summaries.MSG_*` | `_()` при выводе |
| **Maintainer / technical** | lock drift, git verify | English OK — см. `audit_user_strings.py` |
| **Container** | `inside_docker_app/` | **только English** (ADR-008) |

## CI (4.5)

Job **`i18n`** в `ci.yml` на каждый PR:

```bash
python3 scripts/check_i18n_catalog.py   # 0 missing msgid → pass
python3 scripts/audit_user_strings.py --summary   # inventory, non-blocking
```

Рекомендуемый required check на `4.7.0-dev`: **i18n** (вместе с lint, unit, contract).

## Обновление после правки `_('...')`

```bash
python3 scripts/sync_i18n_catalog.py
python3 scripts/check_i18n_catalog.py
```

Ручной путь (xgettext):

```bash
xgettext -o dev_project/i18n/main.pot -L Python -k_ dev_project/*.py dev_project/**/*.py
msgmerge -U dev_project/i18n/ru_RU/LC_MESSAGES/main.po dev_project/i18n/main.pot
# редактировать .po
msgfmt -o dev_project/i18n/ru_RU/LC_MESSAGES/main.mo \
  dev_project/i18n/ru_RU/LC_MESSAGES/main.po
```

`sync_i18n_catalog.py` обновляет **ru_RU** (переводы в `RU_MESSAGES` + `PLAN_L10N_RU`) и **en_US** (msgstr = msgid).

## `odpm plan` (`plan_msg`)

Строки `reason` / `description` / plan-warnings локализуются **в момент сборки плана** через `dev_project/plan/l10n.py::plan_msg()` (не при выводе таблицы). Новые msgid добавляйте в `scripts/plan_l10n_ru_batch.py` или `RU_MESSAGES`, затем `sync_i18n_catalog.py`. `check_i18n_catalog.py` учитывает и `_('...')`, и `plan_msg('...')`.

`.mo` в git (исключение в `.gitignore`), в пакет через `package-data` в `pyproject.toml`.

## Plural forms

В 4.5 host-каталог не использует `ngettext`; при добавлении plural-only строк — обновить ADR-008 и каталог.
