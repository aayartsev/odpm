# Which documentation to read

The site hosts several **documentation versions**. Use the version switcher in the page header. Quick reference:

| Version | Audience | Installing odpm |
|---------|----------|-----------------|
| **stable** (recommended) | production, new users | APT `stable` suite (**4.6.0**), [v4.6.0 release](https://github.com/aayartsev/odpm/releases/tag/v4.6.0) |
| **4.7.0-beta** | early adopters of 4.7 | APT/YUM **`testing`**, [v4.7.0-beta release](https://github.com/aayartsev/odpm/releases/tag/v4.7.0-beta) |
| **4.6.0-beta** | archived 4.6 pre-release | APT/YUM **`testing`**, [v4.6.0-beta release](https://github.com/aayartsev/odpm/releases/tag/v4.6.0-beta) |
| **4.5.0-beta** | archived 4.5 pre-release | APT/YUM **`testing`**, [v4.5.0-beta release](https://github.com/aayartsev/odpm/releases/tag/v4.5.0-beta) |
| **4.4.3-beta**, **4.4.2-beta**, … (archive) | archived 4.4 pre-releases | [4.4.3-beta](https://github.com/aayartsev/odpm/releases/tag/v4.4.3-beta), [4.4.2-beta](https://github.com/aayartsev/odpm/releases/tag/v4.4.2-beta) |
| **dev** | odpm development | not for production |

## Quick links

- Stable install hub: `/stable/install/` (alias **stable**, currently **4.6.0**)
- Pre-release 4.7 beta: `/4.7.0-beta/install/`
- Archived 4.6 beta: `/4.6.0-beta/install/`
- Archived 4.3: `/4.3.0/install/` (alias **4.3** in the switcher)
- Archived 4.5 beta: `/4.5.0-beta/install/`
- Archived 4.4 betas: `/4.4.3-beta/install/`, `/4.4.2-beta/install/`
- Development: `/dev/install/`

!!! tip "Installed odpm ≠ docs version"
    `odpm --version` shows the **installed** manager. Site docs are versioned **separately** by release tags and the `stable` alias.
